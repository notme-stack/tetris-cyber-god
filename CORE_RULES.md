
# Core Rules for Project Tetris_Cyber_Gods
1. **Platform Target**: This is an **Android-ONLY** application. No code or assets should be created for iOS, Web, macOS, Windows, or Linux unless absolutely necessary for the Android build process or testing (e.g., unit tests).
2. **Consultation Required**: If a non-Android file (e.g., `ios/`) appears necessary, you MUST consult the user before creating it.
3. **Consistency**: Use `Tetris_Cyber_Gods` for display names and `tetris_cyber_gods` for package names.
